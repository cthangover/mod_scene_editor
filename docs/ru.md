# Редактор сцен — места новеллы без ручного JSON

Редактор сцен — окно поверх запущенной игры для мест визуальной новеллы: фоны сцены, её звук, сценарий по умолчанию и список её сценариев. Сохранённую сцену игра узнаёт сразу, а **▶ Перейти в сцену** переносит вас туда — можно построить место и зайти в него без перезапуска.

## Как открыть

Нажмите кнопку с молотком на игровом тулбаре и выберите **Редактор сцен** в наборе инструментов. Окно остаётся открытым при смене сцен; его можно двигать, менять размер и закрыть крестиком.

## Новое место

![Редактор сцен с выбранной сценой my_novel_town шаблона новеллы: слева список сцен, в центре фон town_entry и он же в фонах сцены, справа «Сохранять в» my_novel_game и сценарий сцены my_novel_town.](assets/scene-editor.jpg)

1. Нажмите **+ Новая сцена**, введите id сцены (латиница, цифры и `_`; на него ссылаются `switch_scene` и заголовки сценариев) и выберите мод в **Сохранять в**.
2. Выберите фон в списке и нажмите **+ Добавить фон в сцену** (или дважды щёлкните его). У сцены может быть несколько фонов; при входе один выбирается случайно.
3. Выберите **Звук** (кнопка воспроизведения даёт его послушать) и, если нужно, **Сценарий по умолчанию**, который играет, когда других сценариев сцены не осталось.
4. **Сохранить** (Ctrl+S) записывает `scenes/<id>.json` в выбранный мод.
5. **+ Новый сценарий** создаёт файл сценария этой сцены в выбранном моде. Если установлен `scenario_editor`, файл сразу открывается там; **Открыть** (или двойной щелчок) открывает существующий сценарий сцены.
6. **▶ Перейти в сцену** завершает текущий диалог и входит в сцену.

## Чьи файлы записываются

Сцена — это сумма файлов `scenes/<id>.json` всех модов. Редактор пишет только файл мода, выбранного в **Сохранять в**, и выбрать можно только моды, установленные папками. Фоны и настройки из файлов других модов показаны заблокированными; правка чужой сцены создаёт в вашем моде файл, который дополняет её. **Удалить** удаляет только файл выбранного мода.

## Если что-то не так

- **«Открыть» неактивна.** Редактор сценариев не установлен; добавьте `scenario_editor` (или набор «Инструменты разработчика»). Новые файлы сценариев создавать всё равно можно.
- **В «Сохранять в» нет модов.** Писать можно только в моды-папки; упакованные `.zip`-моды только для чтения.
- **Нового фона или звука нет в списках.** Нажмите **Пересканировать** после добавления файлов в мод.

## Зависимости

`tools_base`, `scenario_tools_base`, `dialog_base`, `ui_base`. Необязательно: `scenario_editor` для кнопки **Открыть**.
Старый пакет `editor_tools` ставит этот мод вместе с остальными авторскими окнами.
