# シーンエディター — 手書きの JSON なしでノベルの場所を作る

シーンエディターは、実行中のゲームの上に開くビジュアルノベルの場所のためのウィンドウです。シーンの背景、音、既定のシナリオ、シナリオの一覧を扱います。保存したシーンはゲームがすぐに認識し、**▶ シーンへ移動**でそこへ行けるので、場所を作ってそのまま再起動せずに入れます。

## 開き方

ゲームのツールバーのハンマーボタンを押し、ツールボックスで**シーンエディター**を選びます。ウィンドウはシーンが変わっても開いたままで、移動、サイズ変更、× で閉じることができます。

## 新しい場所を作る

![ノベルのテンプレートの my_novel_town を選んだシーンエディター: 左にシーンの一覧、中央に背景 town_entry（シーンの背景にも入っている）、右に保存先 my_novel_game とシーンのシナリオ my_novel_town。](assets/scene-editor.jpg)

1. **+ 新しいシーン**を押し、シーン id（ラテン文字、数字、`_`。`switch_scene` とシナリオのヘッダーがこれを参照します）を入力し、**保存先**で MOD を選びます。
2. 一覧で背景を選び **+ シーンに背景を追加**を押します（ダブルクリックでも可）。シーンには複数の背景を持たせられ、入るたびにひとつがランダムで選ばれます。
3. **音**を選び（再生ボタンで試聴できます）、必要なら**既定のシナリオ**を選びます。シーンのほかのシナリオが残っていないときに再生されます。
4. **保存**（Ctrl+S）で `scenes/<id>.json` を選んだ MOD に書きます。
5. **+ 新しいシナリオ**は選んだ MOD にこのシーンのシナリオファイルを作ります。`scenario_editor` があればすぐにそこで開きます。**開く**（またはダブルクリック）でシーンの既存のシナリオを開きます。
6. **▶ シーンへ移動**は進行中のダイアログを終わらせてシーンに入ります。

## 誰のファイルに書くか

シーンは全 MOD の `scenes/<id>.json` ファイルの合計です。エディターは**保存先**で選んだ MOD のファイルだけを書き、選べるのはフォルダーとしてインストールされた MOD だけです。ほかの MOD のファイルから来た背景や設定はロックされて表示されます。他人のシーンを編集すると、あなたの MOD にそれを補うファイルが作られます。**削除**は選んだ MOD のファイルだけを消します。

## うまくいかないとき

- **「開く」がグレーになっている。** シナリオエディターが入っていません。`scenario_editor`（または「開発者ツール」セット）を追加してください。新しいシナリオファイルは作れます。
- **「保存先」に MOD がない。** 書き込めるのはフォルダー MOD だけです。パックされた `.zip` MOD は読み取り専用です。
- **新しい背景や音が一覧にない。** MOD にファイルを追加したら**再スキャン**を押してください。

## 依存関係

`tools_base`、`scenario_tools_base`、`dialog_base`、`ui_base`。任意: **開く**のための `scenario_editor`。
古い `editor_tools` パッケージは、この MOD をほかの作成用ウィンドウと一緒にインストールします。
